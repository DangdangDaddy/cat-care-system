# 猫咪成长健康管理系统 - 需求文档

## 一、项目概述

### 1.1 项目名称
猫咪成长健康管理系统（暂定名：喵喵日记 / CatCare）

### 1.2 项目背景
用户家中有2只约4个月大的猫咪，需要一个Web系统来记录和管理猫咪的成长与健康数据。后续计划引入硬件设备（如监控摄像头）实现自动化数据采集。

### 1.3 目标用户
- 主要用户：家中养猫的宠物主人
- 未来扩展：多猫家庭、宠物社区

---

## 二、核心功能模块

### 2.1 猫咪档案管理

| 功能点 | 描述 |
|--------|------|
| 基本信息 | 姓名、品种、性别、生日、绝育状态、芯片号 |
| 外观特征 | 毛色、眼色、特殊标记 |
| 照片头像 | 支持上传猫咪头像照片 |
| 多猫管理 | 支持添加多只猫咪，切换查看 |

### 2.2 成长照片记录

| 功能点 | 描述 |
|--------|------|
| 照片上传 | 支持单张/批量上传，支持拖拽 |
| 时间轴展示 | 按时间线展示猫咪成长照片 |
| 标签分类 | 支持"日常"、"玩耍"、"睡觉"、"医院"等标签 |
| 年龄标记 | 自动计算拍照时的猫咪年龄（如"3个月15天"） |
| 备注描述 | 每张照片可添加文字描述 |
| AI照片生成（未来） | 根据猫咪照片，AI生成各年龄段预测照片 |

### 2.3 体重管理

| 功能点 | 描述 |
|--------|------|
| 体重录入 | 记录日期、体重值（支持kg/g） |
| 体重曲线 | 可视化展示体重变化趋势图 |
| 标准参考 | 幼猫标准体重范围对比（根据品种/年龄） |
| 异常提醒 | 体重异常波动时提醒（如短时间内骤降） |
| 数据导出 | 支持导出体重数据（CSV/Excel） |

### 2.4 进食饮水监控

| 功能点 | 描述 |
|--------|------|
| 手动记录 | 记录喂食时间、食物类型、分量 |
| 饮水记录 | 记录饮水量或饮水行为 |
| 多猫区分 | 标记是哪只猫进食（如果可区分） |
| 进食规律分析 | 分析进食频率、规律性 |
| 食物偏好 | 记录猫咪喜欢的食物类型 |
| 摄像头监控（未来） | 接入摄像头自动识别进食行为 |

### 2.5 排便排尿监控

| 功能点 | 描述 |
|--------|------|
| 记录排便 | 时间、便便状态（正常/软便/稀便/便秘）、颜色 |
| 记录排尿 | 时间、尿量（多/正常/少）、颜色异常标记 |
| 猫砂盆管理 | 多猫砂盆时区分记录 |
| 健康分析 | 异常排便/排尿趋势分析 |
| 提醒功能 | 长时间未排便/排尿提醒 |
| 摄像头监控（未来） | 自动识别如厕行为 |

### 2.6 健康医疗记录

| 功能点 | 描述 |
|--------|------|
| 疫苗记录 | 疫苗名称、接种日期、下次接种时间、提醒 |
| 驱虫记录 | 体内/体外驱虫时间、药品名称、下次提醒 |
| 就诊记录 | 医院名称、诊断结果、处方药、费用 |
| 用药记录 | 药品名称、剂量、用药时间、疗程 |
| 过敏记录 | 记录猫咪过敏的食物或药物 |

### 2.7 提醒与通知

| 功能点 | 描述 |
|--------|------|
| 疫苗提醒 | 疫苗到期前提醒 |
| 驱虫提醒 | 驱虫到期前提醒 |
| 用药提醒 | 定时用药提醒 |
| 异常提醒 | 体重异常、排便异常等健康预警 |
| 通知方式 | 站内通知 / 邮件 / 微信推送（未来） |

## 四、非功能性需求

### 4.1 用户体验
- 响应式设计，支持PC和移动端访问
- 界面简洁可爱，符合宠物主题
- 操作便捷，减少录入步骤

### 4.2 性能要求
- 页面加载时间 < 2秒
- 图片支持压缩和懒加载

### 4.3 安全要求
- 用户数据加密存储
- 照片等隐私数据安全保护

### 4.4 扩展性
- 预留硬件接入接口（摄像头、智能喂食器等）
- 预留AI功能扩展接口
- 支持后续开发移动App

---

## 五、技术架构建议

### 5.1 前端
- 框架：React / Vue 3
- UI组件库：Ant Design / Element Plus
- 图表：ECharts / Chart.js
- 移动端适配：响应式布局

### 5.2 后端
- 框架：Node.js (Express/Koa) / Python (FastAPI/Django)
- 数据库：PostgreSQL / MySQL
- 文件存储：本地存储 / 云存储（阿里云OSS、七牛云）
- 认证：JWT Token

### 5.3 部署
- 前后端分离部署
- Docker容器化
- Nginx反向代理
