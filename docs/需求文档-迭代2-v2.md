## 三、其他功能需求

### 3.1 疫苗接种情况

| 状态 | 说明 |
|------|------|
| 未接种 | 从未接种 |
| 已接种第1针 | 首次免疫 |
| 已接种第2针 | 二次免疫 |
| 已完成全部（3针） | 免疫完成 |

### 3.2 驱虫情况

- **体内驱虫日期**：最近一次体内驱虫时间
- **体外驱虫日期**：最近一次体外驱虫时间
- 自动计算下次驱虫提醒

### 3.3 病史记录

- 支持多条病史
- 字段：病症、日期、治疗情况、备注

### 3.4 相册功能

- 主页相册：展示所有猫咪照片
- 详情页相册：单只猫咪照片管理
- 功能：上传、删除、查看大图

### 3.5 体重记录优化

- 新增：修改、删除体重记录

## 四、多Agent并行开发方案

### 4.1 开发模式

启用 **3-4 个 Codex subagent** 并行开发，虾虾负责协调和指导。

### 4.2 任务分工

| Agent | 任务模块 | 具体内容 |
|-------|----------|----------|
| **Agent-1** | 后端数据层 | 数据库表结构修改、新增API接口、数据迁移 |
| **Agent-2** | 前端表单组件 | 品种毛色选择器、疫苗驱虫录入、病史管理 |
| **Agent-3** | 前端页面 | 主页相册、详情页相册、体重记录优化 |
| **Agent-4** | 联调测试 | 前后端联调、功能测试、Bug修复 |

### 4.3 开发流程

```
时间线（1天 = 8小时）

┌─────────────────────────────────────────────────────────┐
│  Hour 1-2    需求分析 + 数据库设计 + 任务分配            │
├─────────────────────────────────────────────────────────┤
│  Hour 2-6    Agent-1,2,3 并行开发                       │
│              Agent-1: 后端API                           │
│              Agent-2: 表单组件                          │
│              Agent-3: 页面功能                          │
├─────────────────────────────────────────────────────────┤
│  Hour 6-7    Agent-4 联调测试                           │
├─────────────────────────────────────────────────────────┤
│  Hour 7-8    整合部署 + 最终测试                        │
└─────────────────────────────────────────────────────────┘
```

### 4.4 协作机制

1. **Git分支策略**：
   - `feature/backend` - Agent-1
   - `feature/frontend-form` - Agent-2
   - `feature/frontend-album` - Agent-3
   - `dev` - 整合分支

2. **沟通机制**：
   - Agent之间通过代码注释和接口文档协作
   - 虾虾负责解决冲突和协调进度

3. **接口约定**：
   - Agent-1 先定义好API接口文档
   - Agent-2,3 根据接口文档并行开发前端

## 五、API接口设计

### 5.1 猫咪信息相关

```
PUT  /api/cats/{id}          # 更新猫咪信息（含新品种毛色字段）
GET  /api/breeds             # 获取品种列表
GET  /api/coat-colors        # 获取毛色列表
```

### 5.2 健康档案相关

```
POST /api/cats/{id}/medical-history      # 添加病史
PUT  /api/cats/{id}/medical-history/{mid}# 修改病史
DEL  /api/cats/{id}/medical-history/{mid}# 删除病史
```

### 5.3 相册相关

```
GET  /api/cats/{id}/photos        # 获取照片列表
POST /api/cats/{id}/photos        # 上传照片
DEL  /api/photos/{pid}            # 删除照片
GET  /api/photos/all              # 获取所有猫咪照片（主页用）
```

### 5.4 体重记录相关

```
PUT  /api/weights/{id}            # 修改体重记录
DEL  /api/weights/{id}            # 删除体重记录
```

## 六、数据库变更

### 6.1 cats 表新增字段

```sql
ALTER TABLE cats ADD COLUMN breed VARCHAR(100);
ALTER TABLE cats ADD COLUMN coat_color VARCHAR(100);
ALTER TABLE cats ADD COLUMN vaccination_status VARCHAR(20) DEFAULT 'none';
ALTER TABLE cats ADD COLUMN last_internal_deworming DATE;
ALTER TABLE cats ADD COLUMN last_external_deworming DATE;
```

### 6.2 新增表

```sql
-- 病史表
CREATE TABLE medical_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    cat_id INTEGER NOT NULL,
    disease VARCHAR(200),
    illness_date DATE,
    treatment TEXT,
    notes TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (cat_id) REFERENCES cats(id)
);

-- 照片表
CREATE TABLE photos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    cat_id INTEGER NOT NULL,
    url VARCHAR(500) NOT NULL,
    thumbnail VARCHAR(500),
    description VARCHAR(200),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (cat_id) REFERENCES cats(id)
);
```
