##### B. 新增"疫苗接种情况"

**【疫苗接种选项】**

| 序号 | 接种状态 | 说明 |
|------|----------|------|
| 1 | 未接种 | 从未接种过疫苗 |
| 2 | 已接种第1针 | 已完成首次免疫 |
| 3 | 已接种第2针 | 已完成二次免疫 |
| 4 | 已完成全部接种（3针） | 免疫程序完成 |

**【疫苗接种知识】**

猫咪核心疫苗（猫三联）：
- **第1针**：通常在 6-8 周龄接种
- **第2针**：间隔 3-4 周后接种
- **第3针**：再间隔 3-4 周后接种
- **加强针**：此后每年接种一次

**可选疫苗**：
- 狂犬疫苗：建议每年接种

**数据结构**：
```json
{
  "vaccination_status": "completed",  // none, first, second, completed
  "last_vaccine_date": "2025-12-01",
  "next_vaccine_date": "2026-12-01",
  "vaccine_records": [
    {"date": "2025-10-01", "type": "猫三联第1针"},
    {"date": "2025-11-01", "type": "猫三联第2针"},
    {"date": "2025-12-01", "type": "猫三联第3针"}
  ]
}
```

##### C. 新增"驱虫情况"

**【驱虫类型】**

| 序号 | 驱虫类型 | 说明 |
|------|----------|------|
| 1 | 体内驱虫 | 预防蛔虫、绦虫等肠道寄生虫 |
| 2 | 体外驱虫 | 预防跳蚤、蜱虫、螨虫等 |

**【驱虫频率建议】**

| 猫咪状态 | 体内驱虫频率 | 体外驱虫频率 |
|----------|--------------|--------------|
| 幼猫（<6月龄） | 每月1次 | 每月1次 |
| 成年猫（室内） | 每3个月1次 | 每1-2个月1次 |
| 成年猫（可外出） | 每月1次 | 每月1次 |

**【录入方式】**

- 支持录入最近一次体内驱虫日期
- 支持录入最近一次体外驱虫日期
- 系统根据日期自动计算下次驱虫提醒

**数据结构**：
```json
{
  "deworming": {
    "internal": {
      "last_date": "2026-03-01",
      "next_date": "2026-06-01"
    },
    "external": {
      "last_date": "2026-03-01",
      "next_date": "2026-04-01"
    }
  }
}
```

### 6.1 品种与毛色智能匹配规则

```python
def format_breed_display(breed: str, coat_color: str) -> str:
    """智能匹配品种+毛色展示文本"""
    
    # 品种简称映射
    breed_short = {
        "英国短毛猫": "英短",
        "美国短毛猫": "美短",
        "中华田园猫": "中华田园",
        "俄罗斯蓝猫": "蓝猫",
    }
    
    # 毛色映射
    coat_map = {
        "纯灰色/蓝色": "蓝猫",
        "橘色/橘猫": "橘猫",
        "虎斑/狸花": "狸花猫",
        "三花色": "三花猫",
        "银渐层": "银渐层",
        "金渐层": "金渐层",
    }
    
    # 智能匹配
    short_breed = breed_short.get(breed, breed)
    coat = coat_map.get(coat_color, coat_color)
    
    return f"{short_breed}{coat}"
```
