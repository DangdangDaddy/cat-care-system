# 🐱 猫咪成长健康管理系统

记录和管理猫咪的成长与健康数据。

## 项目结构

```
cat-care-system/
├── frontend/     # Vue 3 前端
├── backend/      # FastAPI 后端
└── docs/         # 项目文档
```

## 技术栈

- **前端**: Vue 3 + Element Plus
- **后端**: Python + FastAPI
- **数据库**: SQLite

## 功能模块

- 猫咪档案管理
- 成长照片记录
- 体重管理
- 进食饮水监控
- 排便排尿监控
- 健康医疗记录
- 提醒通知
